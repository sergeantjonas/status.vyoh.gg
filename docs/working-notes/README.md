## Status convention

| State | Meaning |
|---|---|
| **Active** | Has unshipped work. |
| **Shipped** | All planned work landed. Kept for reference while its decision log still carries weight. |
| **Parked** | Deliberately deferred for a stated reason. |
| **Reference** | Living catalog or append-only log; never completes. |
| **Index** | Reserved for this file. |
